## Errors found & fixed (build baseline → green)
1. **Tailwind v4 CSS in globals.css** — starter shipped v4 syntax
   (`@custom-variant`, `@theme inline`, `@import "shadcn/tailwind.css"`,
   `@import "tw-animate-css"`) against installed tailwindcss 3.4.19.
   → Rewrote `app/globals.css` + `tailwind.config.ts` to Tailwind v3 with the
   SSS palette (royal/navy/footer-navy/paleblue/softblue/body-text/
   muted-text/line/cream/warmorange/warmbrown).
2. **Missing `hasEnvVars`** — starter `lib/utils.ts` only exported `cn`.
   → Restored `hasEnvVars` + helpers (`normalizePhone`, `formatPhone`,
   `clamp`, `sleep`).
3. **`--spacing(4)` v4 function in `components/ui/card.tsx`** — generated
   invalid CSS (`var(--spacing(4))`), broke Turbopack CSS parsing at
   `globals.css` lines 2037/2267.
   → Rewrote card.tsx with plain `p-4/gap-4 | p-3/gap-3` spacing classes.
4. **`asChild` unsupported** on `@base-ui/react` components (button,
   dropdown trigger). Present in `auth-button.tsx`, `theme-switcher.tsx`,
   new navbar/share buttons.
   → Replaced with `buttonVariants()`-styled Links, base-ui `render` prop
   for the dropdown trigger, and styled anchors.
5. **ESLint scanning `.next/` build output** — `eslint .` linted Turbopack
   chunks (`exports`/`require`/`@ts-ignore` noise).
   → Added `ignores: [".next/**", out, build, node_modules, logs]` to
   `eslint.config.mjs`.
6. **`new Date()` in server footer** — blocked static prerender.
   → Hoisted to module-scope `currentYear` const.
7. **`Date.now()` flagged** — TanStack Query's `QueryCache.build` sets
   `updatedAt = Date.now()` at render; `/products` is the only page with
   `useQuery`. Route segment config is forbidden under `cacheComponents`.
   → Made `/products` dynamic via `await connection()` + `export const
   instant = false`.
